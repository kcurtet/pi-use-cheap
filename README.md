# Moved to pi-turnkit

This package is now part of [pi-turnkit](https://github.com/kcurtet/pi-turnkit),
which unifies it with think-hard (and future turn-scoped modes):

```bash
pi uninstall git:https://github.com/kcurtet/pi-use-cheap
pi install git:https://github.com/kcurtet/pi-turnkit
```

The `_` prefix works exactly the same; configuration is now
`/turnkit config _ provider/model`.
